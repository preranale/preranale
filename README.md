## Projects

### [Data Flywheel Pipeline](https://github.com/preranale/data-flywheel)
> *A movie recommendation system that retrains itself — no human intervention needed*

Built an end-to-end ML data flywheel with 7 decoupled microservices. User feedback (clicks, ratings, skips) flows through Redis Streams → ETL pipeline → automatic retraining → model hot-reload. SVD matrix factorisation on 100k real MovieLens ratings achieves RMSE 0.947, 100% coverage.

`FastAPI` `Redis Streams` `SVD` `MLflow` `React` `Docker Compose`

---

### [Mnemo](https://github.com/preranale/mnemo) *(in progress)*
> *An AI assistant that actually remembers you*

Solving three real GenAI problems in one system — persistent memory across sessions, RAG grounding in your documents, and hallucination detection with confidence scoring. LangGraph orchestrates the full pipeline: memory retrieval → document search → LLM generation → fact verification → memory extraction.

`FastAPI` `LangGraph` `ChromaDB` `Claude API` `PostgreSQL` `React`
